# Davin Juandika — Cartoony Pixel Space Portfolio

Interactive personal portfolio built with **Vue 3**, **Vite**, **Vue Router**, and **Tailwind CSS**, featuring custom pixel-art SVG sprites, 8-bit Web Audio synthesizer SFX, and space-sector navigation.

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production (Vercel / GitHub Pages):**
   ```bash
   npm run build
   ```

## Folder Structure

- `src/data/profile.js` — Edit your bio, email, social links, and skill bars here.
- `src/data/projects.js` — Add or update portfolio projects here.
- `src/composables/useSfx.js` — 8-bit Web Audio API sound effects generator.
- `src/views/` — `HomeView`, `AboutView`, `ProjectsView`, and `ContactView`.
